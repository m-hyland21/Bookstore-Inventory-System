# Bookstore Inventory Management System

## Project Overview

A Python-based bookstore inventory management system developed as part of a three-person university group project for the Business Information Systems module at Ulster University.

The application allows users to manage book inventory, update stock levels, generate reports and visualise book data through a menu-driven interface.

## Features

- Display all books and their details
- Generate inventory summary and genre reports
- Add new books to the inventory
- Search for books and update stock quantities
- Sort books alphabetically by author
- Generate bar charts showing books by genre
- Identify books with low stock

## Technologies Used

- Python
- CSV file handling
- Matplotlib (data visualisation)

## How to Run

1. Download `group_4.py` and `Books_data.csv`.
2. Ensure both files are saved in the same folder.
3. Install Matplotlib using `pip install matplotlib`.
4. Run the program using `python group_4.py`.
5. Follow the on-screen menu to access the available features.
